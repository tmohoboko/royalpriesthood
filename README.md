# Royal Priesthood

Interactive tea party programme, with expandable sessions, quick links, printing, and full-screen viewing.

Open `royal_priesthood_interactive_programme.html` locally or deploy this directory to Vercel. The root URL serves the programme through `vercel.json`.

Live programme: https://royalpriesthood-two.vercel.app

To publish updates, run `npx vercel deploy --prod` from this directory.
